\chapter{Future Work}

\section{Introduction}

Although the implemented system satisfies its functional and performance objectives, 
multiple opportunities exist for further improvement and expansion.

This chapter outlines potential future developments that could enhance system capability, 
robustness, scalability, and technological sophistication.

% ------------------------------------------------

\section{Closed-Loop Control Implementation}

The current system operates primarily under open-loop control for motor speed and steering position.

Future work may include:

\begin{itemize}
	\item Integration of wheel encoders
	\item Implementation of PID speed control
	\item Closed-loop steering angle correction
\end{itemize}

Closed-loop control would improve:

\begin{itemize}
	\item Motion accuracy
	\item Load compensation
	\item Terrain adaptability
\end{itemize}

% ------------------------------------------------

\section{Migration to Real-Time Operating System}

While the cooperative loop model has proven sufficient, 
migration to an RTOS could provide:

\begin{itemize}
	\item Task prioritization
	\item Independent timing domains
	\item Improved scalability
	\item Deterministic multi-task scheduling
\end{itemize}

An RTOS-based implementation would be especially beneficial if the system integrates:

\begin{itemize}
	\item Video streaming
	\item Advanced sensor fusion
	\item Autonomous navigation algorithms
\end{itemize}

% ------------------------------------------------

\section{Advanced Communication Protocol}

Enhancements to the custom communication protocol may include:

\begin{itemize}
	\item Packet sequencing and acknowledgment
	\item Encryption for secure communication
	\item Adaptive data rate control
	\item Error correction mechanisms
\end{itemize}

These additions would improve reliability in high-interference environments.

Internet connectivity would transform the system from a local controller into a distributed control platform.

\section{Summary}

The presented system establishes a modular and scalable embedded control platform.

Future developments may enhance:

\begin{itemize}
	\item Control precision
	\item Communication robustness
	\item Energy efficiency
	\item Autonomy level
	\item Hardware integration
\end{itemize}

The current architecture was intentionally designed to accommodate such expansions without requiring fundamental redesign.

This confirms that the project serves not only as a functional implementation but also as a foundation for continued technological advancement.
